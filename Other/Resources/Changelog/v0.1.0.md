# Release notes

## Changes

- Initial release.
- Added the inventory-model (location, building, area, container, item) with the distinction between target place and real place of an item, including its persistence in PostgreSQL, MariaDB and the transient persistence.
- Added the assignment of groups to inventory-objects; the read-access applies to everything which is contained in an assigned object.
- Added the page "Groups" to the admin-area to create and delete groups and to assign inventory-objects to them.
- Added a reusable dropdown with an inline-search to select an inventory-object.
- Updated GRYLibrary to 2.1.5 and Swashbuckle.AspNetCore to 10.2.3.
